# Clash 面板原型（可交互）

SwiftUI 静态→可交互原型：演示窗口 + 真状态栏浮层，共享同一个 `PrototypeModel`。
全部是本地假数据，**不接触真实内核 / 网络 / 系统代理**，零第三方依赖。

## 运行

```bash
./Scripts/run-prototype.sh
```

会同时出现：

- **状态栏图标**（点开是 340 × 626 的面板浮层）
- **演示窗口**：模拟桌面壁纸 + 居中面板 + 右侧「原型控制」栏

两个场景共享状态：在演示窗口里切模式 / 选节点，浮层里立即可见，反之亦然。

## 能点的东西

| 位置 | 行为 |
|---|---|
| 连接磁贴 | 未运行 → 启动中（0.8s spinner）→ 代理中；代理中 → 已就绪（只关系统代理）；已就绪 → 代理中 |
| 代理模式分段 | 点击即切；选中段位移；←/→ 可切；「直连」时状态条显示直连 |
| TUN 磁贴 | 已关闭 → 需要授权 →（1.2s）→ 已开启；再点回已关闭 |
| 节点行 | 点击立即选中（行底色 + 加粗，无 ✓）；超时节点不可点 |
| 卡头「还有 N 个 ›」 | 推入二级面板（横向 16pt + 淡入），`‹` 返回；Esc 在二级页返回、在首层关浮层 |
| 策略组「全部 ›」 | 全部策略组面板，星标控制首屏固定（主组不可取消） |
| 流量曲线 | 1Hz 假数据、60 点左移、速率同步变化；rail 可暂停 |
| 底栏 | 刷新 = 时间变「刚刚更新」；连接列表 / 日志 = 占位面板；设置 = 打开演示窗口 |

状态栏图标按 §4.1 语义近似：未运行 = 描边 + 斜线；已就绪 / 直连 = 描边；代理中 = 实心；失败 = 实心 + 红点。

## 原型控制栏

重置到「代理中」· 外观（系统/浅色/深色）· 壁纸（浅/深/纯色）· 显示错误 banner · 显示空态 · 模拟失败（启动 1.5s 后回滚进失败态）· 暂停曲线。

## 自检

```bash
cd Prototype
swift build
./.build/debug/ClashPrototype --measure              # 打印面板尺寸
./.build/debug/ClashPrototype --snapshot /tmp/shot3   # 代理中浅/深、失败、空态、二级面板
./.build/debug/ClashPrototype --selftest             # 驱动状态机，验证过渡 / 回滚 / 二级面板
```

## 已知限制

- `MenuBarExtra` 没有公开的关闭 API：Esc 在首层用 local key monitor 关掉 key window。
- 连接列表 / 日志 / 订阅 / 全部策略组是占位 `NSPanel`，明确写「原型未实现」，不编造内容。
- 面板里的动效只覆盖 §5 的几类（磁贴按下、列表选中、二级推入、hover），曲线 1Hz 直接重绘、不做插值。
