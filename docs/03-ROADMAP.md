## 风险登记

| 风险 | 影响 | 应对 |
|---|---|---|
| mihomo 二进制需与应用一起签名，helper 以 root 启动 | 启动被 Gatekeeper 拒绝 | 二进制放 App bundle 内、同 profile 签名；helper 校验签名后再 spawn |
| TUN 与系统 VPN/DNS 冲突 | 用户断网 | 启动前检测现有 utun/路由；失败回退系统代理模式并提示 |
| 系统代理残留 | 用户全机断网（最严重） | 快照 + 崩溃恢复 + 卸载清理，三重保障 |
| macOS 版本差异（15 vs 26） | API 行为不一致 | 最低 15；仅用 15 稳定 API，新版特性做可用性判断 |
| GPL-3.0 合规 | 分发受阻 | 独立进程 + 附 LICENSE 与源码地址（见 `adr/0001`） |

## 并行原则

- 同一里程碑内，UI 与内核/服务可并行；但 `Core/Services` 契约先冻结再并行
- 每个里程碑结束：更新 `plan/CURRENT.md`、打 tag `v0.x`
