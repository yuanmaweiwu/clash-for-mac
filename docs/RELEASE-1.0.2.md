# Clash 1.0.2

本次解决开机自启后的两个「要从头点一遍」的问题：**接管方式**和**选中节点**。

## 新增

### 开机恢复上次接管方式

关机前开着 TUN 或系统代理，下次启动会自动恢复，不需要再点磁贴。

- 记住的是「意图」：手动开启 TUN → `tun`，手动开代理 → `proxy`，主动关闭 → `off`；退出清理、崩溃、内部重启都不会覆盖
- 启动后等内核就绪，延迟 1.5 秒再接管（给网络与特权组件留时间）
- 失败自动重试 3 次（2s / 5s），仍失败只在面板顶部提示，不弹密码框
- 设置 → 代理 → 「开机恢复上次接管」可关闭（默认开启）

实测：退出 App 再打开，**2.4–2.6 秒**后 TUN 自动开启、`utun` +1、无需密码。

### 恢复上次选中的节点

- 手动选节点后写入 `selection.json`（组名 → 节点名）
- 启动顺序：内核就绪 → 刷新 `/proxies` → 恢复节点 → 恢复 TUN / 代理
- 只恢复 `select` 组；`url-test` / `fallback` 组交给内核自己选
- 节点已不存在（换订阅/删节点）时给一条提示并保留内核默认，不报错

这同时修掉一个隐藏问题：本地内核与 TUN 内核使用不同的 `-d` 目录，过去两边的选中项可能不一致，现在都以 App 侧记录为准。

## 与 1.0.1 相同

- 配置热重载：切订阅 0.055s（TUN 下 pid 与 utun 不变，失败自动回退）
- 菜单栏控制中心面板、系统代理与 TUN 互斥、内核按需下载
- 多订阅、策略组单选、规则 / 连接 / 日志、网络检测（手动触发）
- 单实例、退出还原、崩溃后清理孤儿内核、清理可恢复

## 安装包

| 文件 | 架构 | 内置内核 |
|---|---|---|
| `Clash-1.0.2-arm64.dmg` / `.zip` | Apple Silicon | 否 |
| `Clash-1.0.2-arm64-kernel.dmg` / `.zip` | Apple Silicon | 是 |
| `Clash-1.0.2-x86_64.dmg` / `.zip` | Intel | 否 |
| `Clash-1.0.2-x86_64-kernel.dmg` / `.zip` | Intel | 是 |

每个产物附同名 `.sha256`。

## 系统要求

- macOS 15.0 Sequoia 及以上
- ad-hoc 签名、未公证：首次打开请右键 →「打开」
- 仅 TUN 需要一次管理员授权；开机恢复 TUN 不需要密码
