> 日期：2026-11-13 · 分支 `test`

## 有意保留

1. **空态图标 24pt**（`tray` / `text.alignleft` / `warning`）：规格 §7 明确写 24，属插图不属工具图标。
2. **chevron 9pt、速率箭头 8pt、警示 10pt**：作为字形随文字排版，按 11–14 收会撑坏行高。
3. **hover 才露出 `⋯` / `✕`**：macOS 常见做法，行本身仍可键盘聚焦（P2 记录可见性风险）。
4. **深色卡片对比弱**：`surface/card` 白 0.10 是规格值，靠 1pt hairline 分层。

## 备注

- 截图用 `Scripts/ui-preview.sh` + `CLASH_PREVIEW_INTERACTIVE=1`（键窗口），否则系统按钮在非激活窗口里会画成灰色，容易被误判成「按钮没上色」。
- `before` 基准 = `5e1c6e6`（输入框那一轮已合入、审核修复尚未开始），与 `after` 同一桌面状态，可直接逐像素对比。
- 颜色结论全部来自像素取样 + 对比度实算，不是肉眼估计。
