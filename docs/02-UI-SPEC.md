# Clash UI/UX 规范（v2）

> 适用：macOS 15 Sequoia+，纯状态栏应用（`LSUIElement=true`，无 Dock 图标），SwiftUI 为主。
> 关联：`00-PRODUCT.md`（范围与术语）、`01-ARCHITECTURE.md`（分层与内核状态机）、`03-ROADMAP.md`（里程碑验收）。
> 落地位置：`UI/Tokens/`（本文 §2）、`UI/Components/`（§4）、`Features/Panel/`（§3）。
> 数值即设计意图（标「待微调」的允许 ±2pt）；界面中文为主，字符串一律走 `LocalizedStringKey` / String Catalog，主文案 ≤6 字。

---

## 1. 设计原则

**P1 一屏一次点击（Glance & Act）** —— 弹出即见全局状态；最常用的动作无需滚动、无需二次点击，超过 1 次点击即为缺陷。反例：网页仪表盘的「概览 → 详情 → 操作」三层跳转。

**P2 界面浮在桌面上，不是一页网页** —— 面板由系统材质构成，背后桌面可见。禁止白色实心矩形、顶部品牌大标题、常驻滚动条。参照对象是控制中心与系统弹窗，不是浏览器页面。

**P3 用层级与间隙代替分隔线** —— 控制中心的密度来自「分组卡 + 卡间 12pt 间隙 + 小圆角」，卡内不画线。面板仅 340pt 宽，任何一处 24pt 以上的空白都是浪费一次点击；但 8–16pt 的呼吸区必须留足（「挨太近」同样是缺陷）。

**P4 状态双编码：颜色 + 文字** —— 颜色只做加速识别，不承担唯一信息。延迟点必配数字或「超时」，运行状态必配中文短语；灰度截图与色盲用户都必须可读。

**P5 二级面板是成本，不是功能** —— 能进首屏的绝不做二级页；必须二级的（完整节点列表）保持同尺寸、一次返回。不做三级。

**为什么不像网页仪表盘**：仪表盘追求「一次看全」，控制中心追求「一次做完」。故本产品不做大数字卡片、环形图、柱状图、百分比进度条、卡片瀑布流；曲线只留一条 60 秒迷你流量线，且不画坐标轴与网格。**唯一例外**是订阅磁贴的 3pt 配额条（§4.2）：它是数据可视化而非仪表盘装饰，且数字永远同时给出。

## 2. Design Token

命名 `类别/语义`，落地为 `UI/Tokens/Tokens.swift`。**视图只引用 token：不写 hex，不写 `if colorScheme == .dark`。**

### 2.1 表面层级（共 3 层，禁止第 4 层材质）

面板底永远是 `NSVisualEffectView`（`.popover`，`.behindWindow`）。材质会吃壁纸颜色：深色地图会把面板染成中灰，所以必须有 scrim 把对比度拉回稳定值。

| Token | 用途 | Light | Dark |
|---|---|---|---|
| `surface/panel` | 面板底：系统材质，非自绘 | material | material |
| `surface/panel-scrim` | 压壁纸、稳定对比度（**默认档 B**） | `#FFFFFF` 0.55 | `#000000` 0.40 |
| `surface/card` | 分组卡、磁贴底（默认档 B） | `#FFFFFF` 0.62 | `#FFFFFF` 0.10 |
| `surface/card-hover` | 卡片 hover | `#E9E9EB` @ card alpha | `#FFFFFF` 0.13 |
| `surface/card-pressed` | 卡片按下 | `#000000` 0.12 | `#FFFFFF` 0.14 |
| `surface/row-hover` | 行 hover | `#000000` 0.08 | `#FFFFFF` 0.10 |
| `surface/row-selected` | 选中行底（跟随系统强调色） | accent 0.14 | accent 0.14 |
| `surface/track` | 分段控件轨道、骨架块 | `#000000` 0.06 | `#FFFFFF` 0.08 |
| `surface/opaque` | 需绝对对比的区域：banner、分段选中段 | `#FDFDFD` | `#1F1F22` |

**背景三档（只切一个枚举，不提供 UI 开关）**

`Theme.scrimStyle` 三档，改默认值即可全局切换：`ScrimStyle` = `.light` / `.balanced`（默认） / `.solid`。

| 档位 | scrim Light / Dark | card Light / Dark | 观感 |
|---|---|---|---|
| A 轻透 | 0.28 / 0.28 | 0.58 / 0.07 | 壁纸参与最多，最「浮在桌面上」 |
| **B 中等（默认）** | **0.55 / 0.40** | **0.62 / 0.10** | 压掉深色地图的染色，卡片仍能分层 |
| C 实底 | 0.62 / 0.60 | 0.70 / 0.14 | 接近纸白，几乎不透过壁纸 |

**material 与不透明色的分工**
- material 只做最外层；卡片与行一律半透明 fill，材质全应用只出现一次。开启「提高对比度」或 Reduce Transparency 时，`surface/card` 与 `surface/row-selected` 换用 `surface/opaque` + 描边，保证信息不糊。
- 必须用不透明色：错误/警告 banner、分段选中段、叠在曲线上方的数值——无法保证壁纸对比度。

### 2.2 描边与阴影

| Token | 用途 | Light | Dark |
|---|---|---|---|
| `stroke/hairline` | 卡片边（1pt / 1px） | `#000000` 0.10 | `#FFFFFF` 0.12 |
| `stroke/emphasis` | hover / 分组边界强化 | `#000000` 0.18 | `#FFFFFF` 0.22 |
| `stroke/focus` | 键盘焦点环，2pt，外扩 2pt | accent 0.70 | accent 0.70 |
| `stroke/error` | 失败磁贴 / banner 描边 | `#D70015` 0.30 | `#FF453A` 0.35 |
| `stroke/accent` | 磁贴「开」态描边 | accent 0.40 | accent 0.40 |

**分隔线使用范围**：`stroke/hairline` 只用于**卡片外框**与**状态条底部**。分组卡内部、底栏顶部、二级面板的面包屑与底栏**一律不画横线**——横线在同一块毛玻璃上会切碎视觉。

**1x 屏规则**：线宽取 `Metrics.hairline = 1 / max(1, scale)`。2x 屏 0.5pt（1 物理像素），1x 屏 1pt——写成 `1 / max(2, scale)` 时 1x 上只有 0.5pt，会被舍成 0 像素，等于没有线。验收看「实测像素行数 ≥1 且沿行连续」，不看 token 数值。

**阴影规则**：卡片与磁贴**一律不用阴影**，只用 fill + 1pt 描边分层。面板投影交给 `NSPanel` 原生（`hasShadow = true`），不自绘、不叠多层。

### 2.3 文本

| Token | 用途 | Light | Dark |
|---|---|---|---|
| `text/primary` | 标题、节点名、当前值 | `#1D1D1F` | `#F5F5F7` |
| `text/secondary` | 副标题、未选中段、更新时间 | `#4A4A4F` | `#C7C7CC` |
| `text/tertiary` | 单位、提示、禁用 | `#66666C` | `#98989F` |
| `text/on-accent` | 实心强调色上的文字/图标 | `#FFFFFF` | `#FFFFFF` |

正文与次要文字在默认档 B 上实测 ≥4.5:1；`text/tertiary` 用于 11pt 辅助信息，实测 ≥4.5:1（不再用 42% 白这种不到的灰度）。**禁止纯黑 / 纯白**。

**硬规则：压玻璃的 11pt 一律用 `text/secondary`。** 直接落在面板玻璃上（不在卡片里）的 11pt 辅助字——底栏版本号、主控区「任选其一」提示、行尾状态（未生效 / 测速中 / 刚刚更新）、二级页底栏说明、列表与规则/连接的空态说明——全部用 `text/secondary`。取样实测：`text/tertiary` 压玻璃 3.5–3.7:1（低于 4.5:1 硬线），压卡片才 4.6:1；换 `text/secondary` 后压玻璃 6.1:1。新增同类文字先量背景，再选 token。

### 2.4 语义色

| Token | 用途 | Light | Dark |
|---|---|---|---|
| `accent/base` | 主强调：**跟随系统强调色**（`NSColor.controlAccentColor`） | 系统 | 系统 |
| `success` | 代理中、更新成功 | `#1E8E3E` | `#30D158` |
| `warning` | 降级、待处理、需要授权 | `#B25000` | `#FFD60A` |
| `error` | 启动失败、授权失败 | `#D70015` | `#FF453A` |
| `latency/fast` | < 100ms | `#1E8E3E` | `#30D158` |
| `latency/ok` | 100–300ms | `#A07A00` | `#FFD60A` |
| `latency/slow` | > 300ms | `#B25000` | `#FF9F0A` |
| `latency/timeout` | 超时 / 不可用（空心环 + `text/tertiary`） | `text/tertiary` | `text/tertiary` |
| `traffic/down` | 下行面积与图例（数据色，不跟随强调色） | `#007AFF` | `#0A84FF` |
| `traffic/up` | 上行面积与图例 | `#30B0C7` | `#40C8E0` |

**强调色只用于「选中 / 激活」**：选中行底、开态图标座、焦点环。不用它铺大面积（标题、整卡、banner），也不用它染正文。延迟色阶与流量色**永不跟随强调色**——它们是数据色。

**色彩冲突规则**：当 `accent/base` 与 `success` 色相差 < 30°（用户选了绿/青），系统代理磁贴「已启用」态改用 `text/primary` 实心反白，不用 accent 填充。

### 2.5 圆角

`radius/panel` 16pt（外框）· `radius/card` 12pt（分组卡、磁贴、设置卡）· `radius/row` 7pt（行选中底、chip）· `radius/track` 7pt（分段轨道）· `radius/control` 6pt（输入框、小控件）· `radius/segment-pill` 4pt（分段选中块：轨道 7 − 内距 4 = 3，取 4）· `radius/dot` 50%。

约束：同一容器内不再嵌套 > 6pt 的圆角控件；任何容器圆角不超过 16pt。

### 2.8 字体（只用系统字体，不引入第三方字体）

| Token | 规格 | 用途 |
|---|---|---|
| `font/page-title` | 15pt / semibold | 二级页面标题（面包屑） |
| `font/title` | 13pt / semibold | 卡片头、选中节点名 |
| `font/body` | 13pt / regular | 节点名、磁贴标题、设置行 |
| `font/section` | 11pt / semibold | 区块标题、段名、图例 |
| `font/caption` | 11pt / regular | 副标题、单位、说明 |
| `font/number` | 12pt / medium / `.monospacedDigit()` | 延迟、行内速率 |
| `font/caption-number` | 11pt / medium / `.monospacedDigit()` | 订阅磁贴用量（153pt 宽的极限） |
| `font/probe-value` | 10pt / medium / `.monospacedDigit()` | 网络检测磁贴的值（73×56 内三行排布的极限，仅此一处） |
| `font/number-lg` | 13pt / medium / `.monospacedDigit()` | 状态条速率 |
| `font/status` | 13pt / medium | 状态条文案 |

**只有 10 / 11 / 12 / 13 / 15 五档**，其中 10pt 只服务网络检测磁贴（三行 + 73pt 宽的物理极限；旧的 9pt 已收掉，其余界面不得再用 10）。所有数字强制等宽，否则 1Hz 刷新会左右抖动。中文走系统字体（自动 PingFang SC），**不手动收紧中文字距**；数字与拉丁字母可随字号收 -0.1～-0.15。

**字号与 Dynamic Type 的分工**：状态栏面板是固定尺寸工具面板（与系统控制中心一致），字号固定、**不随 Dynamic Type 放大**；设置窗口、日志等自由排版的界面**必须**支持 Dynamic Type。两者都必须响应系统「加粗文本」。

### 2.9 动效 token

`motion/panel-in` `NSPanel.animationBehavior = .utilityWindow`（系统负责进出，不自绘） · `motion/tile` `.spring(response: 0.22, dampingFraction: 0.82)` · `motion/list` `.easeInOut(0.18)` · `motion/push` `.spring(response: 0.32, dampingFraction: 0.90)` · `motion/height` `.spring(response: 0.28, dampingFraction: 0.80)` · `motion/hover` `.easeOut(0.12–0.16)` · `motion/skeleton` `.easeInOut(1.2).repeatForever` · `motion/chart` `.linear(1.0)`。

**时长区间 150–220ms**（面板进出可到 240ms）；只挂在状态变化上，不做页面级 stagger。Reduce Motion 下所有位移 / 缩放退化为淡入淡出。

### 3.2 分区规格

| 分区 | 高度 | 内边距 | 内容 |
|---|---|---|---|
| 状态条 | 36pt | 左右 12pt | 左：7pt 状态点 + `font/status` 短语；右：`↑`/`↓` + `font/number-lg`，两个速率之间 8pt。底部 1px hairline |
| 主控区 | 138pt + 微文案 19pt | 0，磁贴 gap 10（几何锁定） | 2×2 磁贴：系统代理 / 代理模式 / TUN 模式 / 订阅；磁贴内左右 12pt。区下 6pt 处一行 11pt 微文案（`text/tertiary`，§4.2），高 13pt |
| 曲线卡 | 80pt | 12pt | 标题行 16pt（`font/section` + 双色图例点 + 数值）+ 间距 4pt + 绘制区 36pt |
| 网络检测 | 88pt | 0 | 区块标题 20pt（`font/section`，与「策略组」同款）+ 12pt + 一排 4 个 73×56 磁贴（gap 8 = 316）；见 §4.11 |
| 分组区 | 自适应 | 0 | 区块标题 28pt（`font/section` + 右侧「全部 ›」28pt 命中区）+ 1 张卡（当前展示组） |
| 底部行 | 32pt | 左右 12pt | 左：本 App 版本号（`CFBundleShortVersionString`，如 `v0.4.0`，11pt 等宽 `text/tertiary`）；右：**只有**连接列表（`link`）、规则（`list.bullet.rectangle`）与设置（`gearshape`）三个图标。不放「N 分钟前更新」、刷新按钮、连接数、内核版本号（连接数是用户看不懂的占位，刷新归订阅管理页的 `⋯` 菜单）。**日志入口只在右键菜单**，面板底栏不放 ☰。**不画顶部横线** |

高度预算（单卡）：12（上）+ 36 + 16 + 138 + 19（微文案：6 + 13）+ 16 + 80 + 16 + 88（网络检测）+ 16 + 28（区块标题）+ 136 + 8 + 32（底栏）+ 12（下）= **653pt**，单卡态不需要滚动。
「网络检测 + 策略组」仍是唯一可滚动尾区（可视高 = 680 − 固定头部 333 − 底栏块 52 = **295pt**）：内容将来变高时只在这里滚，面板停在 680，**不靠压缩其它区块换取高度**。
- 空态：**621pt**；首屏永远只有一张分组卡，不存在「双卡 680」形态。
- 微文案那 19pt **恒定预留**（都未启用时显字，其余留白）：否则一开代理面板就矮 19pt，窗口跟着抖。
- 区块之间统一 16（`space/xl`）；网络检测卡内标题与磁贴之间 12（`space/l`）；卡片之间 12；底栏前 8（`space/m`）。

**banner 不额外增高**：错误/断连 banner 出现时从「可滚动尾区」里扣除高度（尾区本就自适应），面板上限不变；此时尾区只露网络检测 + 1 张卡的一部分，可滚动查看。

主界面共 8 个入口：4 个一级动作（系统代理/模式/TUN 模式/订阅）+「全部节点」+ 3 个二级图标（连接列表、规则、设置）。订阅的刷新 / 更新在订阅管理页（行内 `⋯` 菜单），不占首屏。

### 3.3 状态条状态映射（唯一来源：`KernelState` + 系统代理状态）

| 状态 | 状态点 | 文案 | 速率 |
|---|---|---|---|
| `idle` | 空心 `text/tertiary` | 未运行 | `—` |
| `starting` / `stopping` | 6pt `ProgressView` | 启动中 / 停止中 | `—` |
| `running` + 系统代理关 | 实心 `text/secondary` | 已就绪 | 实时（内核在跑就有 `/traffic`，代理关时通常接近 0） |
| `running` + 系统代理开 | 实心 `success` | 代理中 | 实时 |

> **内核生命周期与状态条解耦**：有激活订阅时 App 启动即静默起内核；关代理只还原系统代理、不停内核，节点仍可见可选。状态条只看「内核相位 + 是否接管系统代理」，代理模式（规则/全局/直连）不改变文案。
>
> **流量口径**：速率只取决于「内核是否运行 + WS 是否连通」，与系统代理开关无关。WS 未连通或内核未运行 → `—`；连通后显示真实值（可以是 0）。**永远不用假数据填充**。断连期间保留曲线并标记暂停，不清零。
| `failed` | 实心 `error` | 启动失败 | `—` |
| API/WS 断连 | 实心 `warning` | 连接中断 | `—` |

### 3.4 分组卡内部

- 卡头 32pt：组名 `font/title`，右侧入口「还有 N 个 ›」（`font/caption`，`text/secondary`，N = 组内节点数 − 3）；整条卡头可点 → 二级面板。N = 0 时右侧改显示当前节点名 + `chevron.right`。
- 节点行**固定 3 行**，排序规则：
  1. **选中项恒第一**（切换后立即重排，即使它排在第 9 也提上来）——卡内不能滚，这是「不看高亮也知道现在用哪个」的唯一保证
  2. 其余按**延迟升序**取前 2（低的在前）
  3. 超时 / 未测速的排最后，按配置顺序
- 卡高 = 卡头 32 + 3×32 + **上下内边距 4×2 = 136pt**（左右内边距 12）
- **不设「溢出行」**：早期版本把入口放在第 4 行，会把卡高撑到 156pt 并破坏 626pt 高度预算；入口一律收进卡头右侧。
- 卡内**不滚动**（嵌套滚动在触控板上极易误触）；**卡片内部不画任何分隔线**（卡头与首行之间也不画）——分隔靠留白 + hover 胶囊，横线会把卡片切碎。
- 首屏**固定只有一张卡** = 当前展示组（**单选**）：默认第一个**生效组**（组名取自配置，真实订阅里常是机场名如「机场A」，**不要写死「节点选择」**）；在「全部策略组」点行换组，选择写入 `settings.json` 的 `displayedGroup`，跨启动保留。选中的组消失 / 被删 → 回退第一个生效组，再退回配置里第一组。一个可用组都没有时不占位，面板收窄到 488pt。
- **生效组** = `GET /rules` 里任一条规则的 `proxy` 指向的组（`DIRECT` / `REJECT` / `REJECT-DROP` / `PASS` / `COMPATIBLE` 等内置策略与节点名不算）；组名以 `/proxies` 为准，比较时忽略大小写与空白差异。生效组只用于默认值兜底与打标签，不参与展示组筛选。
- **未生效** = 没被任何规则引用的组。它照常可被选为展示组、照常可选节点可测速，只加一个提示：首屏卡片头右侧「未生效」、全部页行尾「未生效」（均 11pt `text/tertiary`，卡头放在「还有 N 个」左边）。`/rules` 拉取失败时不标——不拿猜测当结论。
- 展示组是 UI 偏好（存 `settings.json` 的 `displayedGroup`），不写进配置、不触发内核重载。

### 3.5 滚动与溢出

- 结构：固定头部（状态条 + 主控区 + 曲线卡）+ 可滚动尾区（**网络检测 + 策略组**）+ 固定底栏。`VStack` 外层，只有尾区 `ScrollView`；分组卡内部不再单独滚动。
- 面板高度 = 内容自然高度，上限 680pt；尾区内容超过 314pt 时**只在这里滚动**（滚动条 `never`），状态条 / 4 磁贴 / 曲线卡 / 底栏位置不动。
- **高度切换与页面切换同帧完成**：面板高度由 `model.panelHeight` 瞬时决定，窗口不单独动画 frame。旧实现里窗口与 SwiftUI 内容各走一条动画，中间帧的圆角会短暂变直角（实测 6 帧约 300ms）。页面推入仍保留淡入 + 16pt 位移，动画只作用在内容容器内，不改变面板外形。
- 二级面板同宽同高，仅中间区域替换；顶部 breadcrumb `‹ 节点选择`，返回保留滚动位置。

图标语义只有一个：**是否正在接管流量**（系统代理或 TUN 生效即「接管」），故「已就绪」为描边态。这是全项目唯一口径，`menubar-ui` §5 的表已按本表对齐。禁止图标旋转动画、内嵌进度环、常驻两段速率。

### 4.2 总开关磁贴（系统代理 / TUN 模式）

标题必须写「系统代理」与「TUN 模式」：两个磁贴是**替代关系（互斥，任选其一）**，都叫「连接 / TUN」会被读成「两个都要开」——用户点了一个发现另一个还空着，就以为没配好。

**结构** 153×64pt，`radius/card`，`surface/card` + `stroke/hairline`，左右内边距 12pt。左 28pt 圆形图标座（`globe.americas.fill` 13pt medium），右侧 8pt 后接标题「系统代理」`font/body` + 副标题 `font/caption`（上下 2pt）。

两个磁贴**共用一套词根**：未启用 / 正在启用 / 已启用 / 正在停用 / 启用失败 / 停用失败。不写「启动 / 关闭」——「启动」像是在说内核，而这个磁贴只管系统代理。

| 状态 | 图标座 | 底/描边 | 副标题 |
|---|---|---|---|
| 未启用 | `surface/row-hover` + `text/secondary` | 默认 | 未启用 |
| 已启用 | `accent/base` 实心 + `text/on-accent` | 描边改 accent 0.40 | 已启用（`text/primary`） |
| 过渡中 | 14pt `ProgressView`（small） | 同未启用态 | 正在启用 / 正在停用 |
| 失败 | `error` 0.14 圆底 + `exclamationmark` | `stroke/error` | 启用失败 / 停用失败（`error`） |

**互斥微文案**：主控区下方 6pt 处一行 11pt `text/tertiary`——「系统代理与 TUN 任选其一」，**只在两个磁贴都未启用时**显字。高度 13pt + 上方 6pt **恒定预留**：显字 / 隐字不改变面板高度，否则一开代理窗口就矮一截；隐字时 `accessibilityHidden`。

**交互**：单击切换，乐观更新；1.5s 无回执则回滚并进失败态。hover 换 `surface/card-hover`，按下换 `surface/card-pressed` + scale 0.98。右键：重启内核 / 查看日志。
**语义边界**：这个磁贴只控制系统代理，**不控制内核**。关代理后内核继续运行，节点列表、测速、切换节点全部照常可用；只有当 App 退出、订阅被删空或内核崩溃时内核才停。
**可访问性**：`.isButton` + `.isSelected`（已启用时）；label「系统代理」，value = 副标题，hint 随态切换「按下启用系统代理」/「按下停用系统代理」。

**其余三个磁贴**
- **TUN 模式**：同结构，图标座用 `shield.lefthalf.filled`（盾牌 = 接管流量，与系统代理的 `globe` 一眼分开），标题「TUN 模式」。副标题：未启用 / 需要授权（`warning` 图标）/ 等待授权 / 已启用 / 授权失败（`error`）/ 启用失败（内核起不来，`error`）。点击「需要授权」时弹系统管理员授权，期间显示「等待授权」。开启失败必须回落系统代理并在顶部 banner 说明，禁止两者同时处于「半开」。
  - **授权前置说明**（首次点「需要授权」时）：先弹我们自己的说明卡，再弹系统密码框。文案：「需要管理员密码安装网络组件，仅此一次」+ 三条说明（只写 `/Library/PrivilegedHelperTools`、只用于开关系统代理与 TUN、可在设置里一键卸载）。用户取消则回到「未启用」，不重复弹。
  - 系统密码框由 macOS 弹出（`osascript … with administrator privileges`），**我们不经手、不存储密码**；密码错误或用户取消 → 「授权失败」，给「重试」按钮。
  - helper 更新会再要一次密码：届时应显示「组件需要更新，需再次授权」而不是无声失败。
- **订阅**：纯导航磁贴，无开关态，**不显示「订阅」标题**。153×64，内容区 129pt（左右各 12）、上下各 12pt 呼吸区，**商家名在左上、数据块贴底**：
  ```
  ┌─────────────────────────┐ 153×64
  │ 机场A                3 │ 13pt 商家名（尾部截断）+ 条数徽标
  │                         │
  │ 12/3 到期   100.8/128 GB │ 11pt 到期（左）· 11pt 等宽用量（右）
  │ ▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬ │ 3pt 满宽用量条
  └─────────────────────────┘
  ```
  - 商家名 = **当前激活的 profile 名**（`font/body` 13pt，单行 `.truncationMode(.tail)`）；未导入时「未添加」`text/secondary`。更新失败追加「· 更新失败」（「已过期」不进名称，由到期行表达）。
  - 右上角条数徽标：仅订阅库 > 1 条时出现（10pt 等宽，底 `surface/track`），只表示条数，不用彩色。
  - 数据行（条上方一行）：左到期 `font/caption` 11pt `text/secondary`（`12/3 到期`；已过期显示「已过期」`error`），右用量 `font/caption-number` 11pt 等宽 `text/primary`（`100.8/128 GB`）。**缺 `expire` 时左侧留白，用量照常右对齐**（不许因此改变右缘位置）。
  - 用量条：**满宽度**（左右各 10pt 内边距之内）3pt 圆角条，track `surface/track`；条**只做辅助**，数字必须在场；>90% 条与数字同步转 `warning`，≥100% 转 `error`，长度按 100% 封顶。
  - 缺 `download` / `total`（本地 YAML / 无 `subscription-info` 头）→ **不画条也不画数据行**，只留商家名。
  - 空库：只显示「未添加」，不画条、不留空行。
  - 激活的 profile 存在多组时，名称永远显示**激活那条**，不显示总数。
  - 可访问性：label「订阅」，value 一句话读全 ——「机场A，已用 100.8 吉字节，共 128 吉字节，12 月 3 日到期」+（多条时）「共 3 条订阅」，hint「按下打开订阅管理」；条本身 `.accessibilityHidden`。
- **代理模式**：见 §4.3，占据磁贴内部，不带图标座。

### 4.3 分段模式切换（规则 / 全局 / 直连）

**结构** 153×28pt 轨道（`radius/track`，`surface/track`），三段等分，段内 4pt 内边距；选中段 `surface/opaque` + `radius/control` + 11pt semibold `text/primary`；未选中 11pt regular `text/secondary`。上方标题「代理模式」（`font/body` 13pt，与同排「系统代理」同阶，`text/secondary`），标题与轨道间距 4pt。

**状态**：默认 / hover（未选中段文字转 `text/primary`）/ 切换中（选中段文字换 12pt `ProgressView`，表示下发配置）/ 失败（选中段描边闪 `error` 一次，400ms 后回真实值）。

**交互**：点击即切换，不做二次确认（可逆高频操作）。键盘 ←/→ 移动并立即生效。
**可访问性**：整体一个 adjustable 元素——label「代理模式」，value「规则」，hint「左右方向键切换」。禁止拆成 3 个按钮。

### 4.4 节点行

**结构**（行高 32pt，左右内边距 12pt）：8pt 延迟点 + `space/s` + 节点名（单行中间截断）+ 弹性空隙 + 延迟（`font/number`，右对齐，右缘距卡边 12pt）。**行尾不设 ✓**。

| 状态 | 表现 |
|---|---|
| 默认 | 延迟点按色阶；名称 `text/primary` |
| hover | `surface/row-hover` + `radius/row`；胶囊左右内缩 **6pt**、上下内缩 **2pt**（高 28pt），文字距胶囊边 6pt |
| 选中 | `surface/row-selected` + 名称 `font/title`（加粗）；**不加 ✓**——浅蓝底 + 字重即选中信号。几何与 hover 胶囊完全一致（同样 6/2 内缩） |
| 超时 / 不可用 | 1pt 空心环，名称 40% 透明，延迟位「超时」，禁用交互 |
| 嵌套策略组 | 延迟点换 16pt `square.stack.3d.up`，右侧 `chevron.right`，副标题「策略组」→ 二级面板 |
| 测速中 | 延迟点换 10pt `ProgressView`，延迟位「—」 |

**交互**：单击立即下发到内核；hover 不自动测速（避免误触流量）。右键：测速 / 复制节点名。
**可访问性**：label = 节点名，value「延迟 32 毫秒，已选中」，hint「按下选择此节点」；不可用节点 value 加「不可用」并置 `.isEnabled = false`。

### 4.5 迷你流量曲线

**结构** 292×36pt 绘制区（卡内 316 − 内边距 24）；上行在下、下行在上，允许重叠但以 0.18 填充 + 1.5pt 顶线区分；标题行含 6pt 双色图例点与右侧数值。
**数据与格式** 60 点 / 1Hz / 窗口 60s；Y 轴自适应（取窗口峰值，最小刻度 1 KB/s）；不画网格、坐标轴、时间刻度；数值按 `B/s → KB/s → MB/s` 换算，保留 1 位小数，`monospacedDigit`，上下行顺序与图例一致。
**空态** 仅一条 `stroke/hairline` 水平虚线 + 居中「暂无流量」（`font/caption`，`text/tertiary`）；**断连态** 曲线 30% 透明，数值变「—」。
**可访问性** 容器 `children: .ignore`；label「实时流量」，value「下载 8.4 兆字节每秒，上传 1.2 兆字节每秒」。**不加** `.updatesFrequently`（1Hz 会打断正在朗读的内容），改为焦点进入时朗读一次。

### 4.6 卡片分组容器

`surface/card` + `radius/card`（12）+ 外框描边（**只有这一条线**）。

- **描边必须连续清晰**：1pt 线宽 + `compositingGroup()` 把「填充 + 描边」合成一层。0.5pt 在 2x 屏上会铺成 2–3px 的半透明过渡带，圆角处还会断，看起来就是毛边。
- **卡内上下各留 4pt 内边距**：卡头 hover 胶囊与末行胶囊距卡顶/卡底 = 4（内边距）+ 2（胶囊内缩）= **6pt**。只留 2pt 时胶囊会贴着圆角，像被切掉一块。
- 可选卡头 32pt（标题左、action 右）；卡内左右边距 12pt；**卡内无任何分隔线**（含卡头与首行之间），行与行靠 hover / 选中胶囊区分。

**胶囊几何（一级卡片）**：行高 32pt，胶囊高 **28pt**（上下各 2pt）、左右各 6pt；卡头 hover 胶囊同参。24pt 的胶囊配 13pt 文字会显得扁（上下各 5.5pt），28pt 才站得住。距卡边的呼吸区由卡片 4pt 内边距提供，合计 6pt。

规则：一卡一语义单元；禁止卡片套卡片；禁止阴影；卡间 gap 固定 12pt。

### 4.7 二级面板（完整节点列表）

同宽同高推入。breadcrumb 行 40pt：`‹`（28pt 热区）+ 组名 `font/page-title`，**不显示当前节点名**（选中态已有底色，重复）；右侧放**批量测速按钮**（`speedometer` 16pt，热区 28pt，label「测速全部节点」）。
- 点击后：所有行延迟位进入「测速中」（10pt `ProgressView`），1–2s 后数值刷新并重排
- **测速进行中按钮必须禁用且不可重复触发**：图标换成 12pt `ProgressView`，hover 不出高亮、点击无响应（不是「排进队列」也不是「重启一轮」）；测速结束后恢复可点。防止用户连点导致多轮竞态、结果互相覆盖
- 列表 `LazyVStack` + `ScrollView`；支持 ↑/↓ 与首字母跳转。Esc 在二级页返回、在首层关面板。**面包屑与底栏都不画横线**。

**排序**：二级节点列表默认按**延迟升序**（超时/未测速排最后，同延迟按配置顺序）；批量测速完成后自动重排，用交叉淡入，不要整列跳动。组列表（「全部策略组」）保持配置顺序，不按延迟排。

**「全部策略组」= 单选展示组，不选节点**：点整行 = 把该组设为当前展示组（替换，不叠加）；选中行 = `surface/row-selected` 蓝底 + 名称**加粗**（与节点行选中同款）。行尾**不放星标、不画 `chevron`**：`GLOBAL` 标「全局」、未生效组标「未生效」（均 11pt `text/tertiary`），生效组行尾不加字。`GLOBAL` 同样可被选中（首屏随之展示 GLOBAL 卡）。节点仍从首屏卡片头的「还有 N 个 ›」进入二级节点列表，这条路径不变。

**未生效标记**：「全部策略组」里没被任何规则引用的组，行尾标「未生效」（11pt `text/tertiary`，`GLOBAL` 除外——它标「全局」）。这类组被选为展示组时，卡片头同样标「未生效」（放在「还有 N 个」左边）。它只是提示——不影响选中，也不影响在组内预选节点（规则以后可能指向它）。`/rules` 拉取失败时不标。

**行规格（二级列表统一）**：行高 48pt（单行名 / 两行：名称 + 「N 个节点」或延迟），左右内边距 12pt；hover 胶囊与一级同参（`pillInsetH` 6 / `pillInsetV` 4）；当前项名称加粗 + `surface/row-selected` 胶囊，**不加 ✓**。行与行之间不留缝，靠胶囊与 hover 区分。

### 4.8 订阅管理面板（二级）

由订阅磁贴推入，同宽同高，复用 §4.7 的推入规范。

- **面包屑 40pt**：`‹` + 「订阅」
- **列表行 48pt**（`radius/row`）：左 12pt 内边距 + 16pt 来源图标（URL= `link`、本地=`doc.text`，`text/tertiary`）→ 8pt → 名称 `font/body` + 第二行 `font/caption` `text/secondary`（`3 小时前更新 · 12.3/100 GB`，到期信息移到行尾轻量文本 `12/3 到期`，缺字段即省、**不补占位**）。**第二行必须在 340pt 宽度内不截断**：宁可少一段，也不要出现 `…`。
- **当前激活行**：左侧 3pt `accent/base` 竖条 + 名称加粗（与节点行一致，**不用 ✓**）；其余行无竖条
- **状态**：更新中 → 行尾 10pt `ProgressView` + 第二行「更新中」；失败 → 行尾 `exclamationmark.triangle.fill`（`warning`）+ 第二行「更新失败，仍在使用旧配置」
- **行操作**：hover 显示行尾「⋯」按钮 → 菜单（更新 / 切换为当前 / 重命名 / 复制链接 / 删除）；删除当前激活项需先提示「将停止内核」，**不使用**确认弹窗处理普通切换
- **顶部右侧**：`＋` 按钮（28pt 热区）→ 直接进入添加订阅页（只支持链接导入）
- **空态**：复用 §7「还没有配置」占位卡，但文案改「还没有订阅」，按钮同上
- **读取三态**（必须，禁止把「读不出来」显示成空列表）：
  - 读取中 → 居中 `ProgressView`（small）+「正在读取订阅…」`font/caption` `text/secondary`
  - 读取失败 → 居中 `exclamationmark.triangle` 22pt `warning` +「读取订阅失败」`font/body` + `ProfileStore.lastError` 原文 `font/caption` +「重试」按钮（重读索引）
  - 已加载且为空 → 上面的空态卡
  - 从订阅磁贴推入时，路由与数据必须同一帧就绪：库还没读完就先同步取一次快照，再改路由（避免先渲染空数组再补数据、闪一下白）
- **禁止**：流量百分比进度条（§8.5）、到期倒计时动画、把「切换」做成开关（它是单选的单选组语义）

### 4.9 设置（面板内页面，不是窗口）

用户明确要求：设置与添加订阅都在面板内完成，只有日志这类才开独立窗口。

- 路由 `.settings`，同宽 340，面包屑 `‹ 设置`，内容可滚动（隐藏滚动条），底部留白 12pt，无底栏
- 内容 6 段，超出面板高度：滚动区底部 12pt 线性渐隐（`mask`，只作用这一页），让「下面还有内容」可见，不再硬切断。渐隐落在内容区 16pt 底部留白内，滚到最底时正文不被吃损
- 三段：**代理**（混合端口 / 允许局域网 / 关代理保留内核）、**订阅**（UA / 默认更新间隔）、**组件与维护**（特权组件状态 + 操作、开机自启、日志级别、打开目录、完全清理）
- 每段 = 11pt 段名 + 一张卡（`surface/card` / `radius/card` / 1pt 描边，内边距 12）；段与段之间 20pt。行高 36pt：label 13pt 左、控件右（系统开关、72pt 数字框、系统下拉 `Picker`、系统尺寸按钮）；**卡内不画横线**
- **所有下拉统一用系统 `Picker`（`.pickerStyle(.menu)`）**：整块控件（含右侧箭头）都可点、hover 有反馈、箭头始终可见。**禁止** `.menuStyle(.borderlessButton)` + `.menuIndicator(.hidden)` + `.fixedSize()` 这种把命中区缩到文字本身、又抹掉可点提示的组合
- 输入框统一 `PanelTextField`：30pt 高、`surface/track` 底 + `stroke/hairline`，hover 换 `stroke/emphasis`，聚焦 1.5pt 强调色描边（关掉系统焦点环）；与上方标签 / 下方说明 ≥8pt
- 端口/日志级别改动后，页内出现一条「需要重启内核生效 · 立即重启」提示行
- 入口：底栏 ⚙ 与 `⌘,` 都推入该页（面板未开时先开面板）
- **仍然允许弹窗的**：系统授权密码框、`NSOpenPanel`、完全清理的破坏性确认

### 4.10 添加订阅（面板内页面）

- 路由 `.subscriptionNew`，面包屑 `‹ 添加订阅`
- URL 输入框占满宽度（`PanelTextField`，30pt 高，13pt，打开即落焦点）+ 一行说明「导入前会用内核校验；失败不会覆盖已有配置」+ 主按钮「导入」（prominent）；间距 12pt，动作行命中区 28pt

- 失败：输入框下方红色文案（**不弹 alert**）
- 成功：自动返回订阅页并选中新项

### 4.11 网络检测磁贴与规则列表

**网络检测（首屏，排在流量卡之后、「策略组」之前）**

四个固定目标：Google / GitHub / Apple / YouTube。一排 73×56（gap 8 = 316），`radius/card` + `surface/card` + 1pt 描边；卡内三行居中（间距 4 / 2）：品牌 logo 16pt + 目标名 11pt `text/secondary` + 值 `font/probe-value`（10pt 等宽）。三者不叠、不贴边。

**Logo 渲染（按品牌实际形态）**

| 目标 | 素材 | 渲染 |
|---|---|---|
| Google | 官方四色 G 矢量（`#4285F4 / #34A853 / #FBBC05 / #EA4335`） | 原色，**非 template** |
| YouTube | 官方红 `#FF0000` 圆角矩形 + 白三角 | 原色，**非 template** |
| Apple | Simple Icons 单色路径 | **template**：浅色黑 / 深色白 |
| GitHub | Simple Icons 单色路径 | **template**：浅色黑 / 深色白 |

素材放 `Assets.xcassets` 的 imageset（Single Scale + Preserve Vector Data），不改色、不描边、不自绘。单色两个勾 Template，多色两个不勾——否则 Google 会变灰、YouTube 会变单色。
> 商标说明：图标来自 Simple Icons（图标集 CC0）与品牌官方配色的矢量；Google / YouTube / Apple / GitHub 商标归各自公司所有，这里仅用于「连通性检测」的指代。

| 状态 | 表现 |
|---|---|
| 未测 | `—`（`text/tertiary`） |
| 测速中 | 10pt `ProgressView`（mini），高度与数字行一致，不跳 |
| 成功 | `NN ms`，按延迟色阶 `<100 / 100–300 / >300`（§2.4） |
| 超时 | 「超时」`text/tertiary`（测过但不通，与「未测」区分） |

- 交互：点**任意一个**磁贴 → 四个一起并发重测（5s 超时）；已在测时忽略重复点击。hover 换 `surface/card-hover`，按下 `surface/card-pressed` + 0.98。
- 标题行右侧刷新：16pt `arrow.clockwise`，28pt 热区，`text/tertiary` → hover `text/primary`；测速中换 12pt `ProgressView` 并禁用（与测速互斥，连点不重启）。
- 数据：`URLSession` 只读 `HEAD`（Google/YouTube `generate_204`、GitHub 首页、Apple `success.html`），测端到端毫秒；**不走 App 的 API 客户端**，系统代理 / TUN 开着时自然被接管。任一端点 5s 未响应或非 2xx/3xx → 超时，不编造「成功但很慢」。
- 自动测：面板每次显示时，若距上次测完 ≥ 60s（或本次运行还没测过）自动测一轮。
- 可访问性：每块 label「<目标> 网络检测」，value「延迟 32 毫秒 / 超时 / 未测速 / 测速中」，hint「按下重测全部目标」。

**规则页（二级，`.rules`）**

- 入口：底栏 `list.bullet.rectangle`，面包屑 `‹ 规则`；同宽 340、同高推入。
- 数据：`GET /rules` → 按配置顺序渲染（不分组、不排序；排查「为什么没命中」靠顺序）。`ClashAPIClient.rules()` + `RuleService`（缓存 + 手动刷新，进页面拉一次；内核停止 / 换配置即作废）。
- 行高 40pt（左右 12）：类型徽标**按内容宽度**（左右 4pt 内边距、`fixedSize`；短类型就该比 `DOMAIN-KEYWORD` 短，不强拉列宽）+ payload（13pt，单行**中间**截断；与徽标固定 8pt 间距，不贴住）+ 行尾目标（11pt `text/secondary`，只 hug 文本、上限 104pt 尾部截断）。徽标底是 `surface/track` + `radius/row` 的整块，**每一行都必须有**。行不可点、无 hover 底。
- 顶部右侧「共 N 条」；滚动条 `never`。
- 空态：「当前配置没有规则」；失败：`exclamationmark.triangle` +「读取规则失败」+ 原因 +「重试」；读取中：`ProgressView` +「正在读取规则…」。

## 5. 动效

| 场景 | 表现 | 参数 | Reduce Motion 降级 |
|---|---|---|---|
| 面板出现 | 由 `NSPanel` 系统动画负责（不叠自定义 spring） | `motion/panel-in` | 系统自动降级 |
| 面板消失 | 淡出 + 下移 4pt | `motion/panel-out` | 仅淡出 80ms |

| 分段选中 / 列表选中 | 选中段位移 + 底色；行底淡入 + 名称字重过渡 | `motion/list`（0.18） | 跳过位移，仅底色 |

## 6. 可访问性

### 6.1 VoiceOver（真实写法）

1. **系统代理磁贴** — label「系统代理」；value「已启用」；hint「按下停用系统代理」；traits `.isButton` + `.isSelected`。
2. **节点行** — label「香港 01」；value「延迟 32 毫秒，已选中」；hint「按下选择此节点」；traits `.isButton` + `.isSelected`。
3. **模式分段** — label「代理模式」；value「规则」；hint「左右方向键切换」；traits `.isAdjustable`。
4. **流量曲线** — label「实时流量」；value「下载 8.4 兆字节每秒，上传 1.2 兆字节每秒」；`children: .ignore`。

规则：所有图标按钮必须有中文 label（`gearshape`→「设置」，`link`→「连接列表」，`ellipsis`→「订阅操作」，`text.alignleft`→「日志」）；不朗读英文单位缩写（写「兆字节每秒」）；主动播报只允许三类事件——内核启停、订阅更新结果、连接中断，且 1.5s 内去重。

### 6.2 键盘

| 按键 | 行为 |
|---|---|
| Tab / Shift-Tab | 顺序（跳过不可聚焦的曲线卡）：系统代理磁贴 → 模式分段 → TUN 模式 → 订阅 → 网络检测磁贴（4 个）→ 分组卡头 → 节点行（卡内自上而下、跨卡续接）→ 连接列表 → 规则 → 设置 |
| Space / Return | 激活焦点元素 |
| ↑ / ↓ | 当前列表内移动焦点（不触发选择，Return 才生效） |
| Esc | 首层关闭面板并把焦点还给状态栏图标；二级页返回上一层 |
| ⌘, | 推入面板内设置页（面板未开时先打开面板） |
| ← / → | 模式分段内切换 |

焦点环 `stroke/focus` 2pt、外扩 2pt、`radius` + 2，用 overlay 绘制，不改变布局尺寸。

### 6.3 对比度

- 正文与次要文字（11pt 起）≥ **4.5:1**。背景是动态壁纸 + 材质，「小字号可降至 3:1」的例外**不适用**，必须靠 scrim 保底；图形元素（图表、延迟点、描边）≥ **3:1**。
- 不以颜色单独承载信息：延迟必配数字或「超时」；运行状态必配短语；TUN 必配「已启用/未启用」。
- **选中行**去掉 ✓ 后，第二通道是**字重**（`body` → `title` semibold）+ `.isSelected` 无障碍 trait；不要仅靠色相区分。
- 灰度下可辨：选中行靠底色明度差 + 字重（不再依赖 ✓）。

## 7. 空态 / 错误态 / 加载态

| 场景 | 文案 | 视觉处理 |
|---|---|---|
| 未导入配置 | 「还没有配置」 | 分组区换占位卡（高 132pt，`radius/card`）：`tray` 24pt `text/tertiary` 居中 + 文案 + 「导入订阅」（prominent）。订阅磁贴副标题「未添加」。**v1 只支持链接导入**，不再提供本地 YAML 入口 |
| 内核启动失败 | 「内核启动失败，点此查看日志」 | 顶部 banner（`surface/opaque` + `stroke/error`，36pt，整条可点）；状态条点转 `error`「启动失败」；系统代理磁贴进失败态；分组区 45% 不透明且禁用 |
| 订阅更新失败 | 「更新失败，继续使用旧配置」 | 订阅管理页顶部提示条（3s 后自动消失）+ 该行转「更新失败，仍在使用旧配置」；订阅磁贴名称后追加「· 更新失败」；不弹窗、不占用底栏 |

| 首次加载 | （无） | 骨架：状态条可先读本地缓存，主控区与分组区各 1 个等高灰块。**禁止显示 0 B/s、0 ms 等假数据** |
| 加载 > 3s | 「正在读取配置…」 | 骨架 + 文案居中于分组区（`font/caption`，`text/secondary`）+ 「重试」文字按钮 |

- 配置校验失败 —— 「配置无效，无法启动」/「打开配置文件夹」
- 端口占用 —— 「端口 7890 被占用」/「更换端口」
- helper 未安装 —— 「需要管理员授权」/「去授权」

## 8. 禁止清单

1. 不做自定义标题栏大色块、不做顶部品牌区或大标题。
2. 不做彩色渐变背景；不做玻璃叠玻璃（material 只出现在最外层）。
3. 不用 >12pt 圆角、不堆叠圆角（卡片内再套大圆角容器）、不给卡片加投影。
4. 不在状态栏常驻大段文字或并列双速率；不用 emoji / 彩色 PNG 图标，状态栏图标必须模板化。
5. 不做网页式仪表盘：大数字卡片、环形图、柱状图、百分比进度条、卡片瀑布流、坐标轴网格。**唯一例外**：订阅磁贴 153×64 内的 3pt 配额条（§4.2）——数据可视化，且必须同时给出数字，不许只靠颜色或长度表意。
6. 不用弹窗/确认框处理可逆高频操作（切模式、切节点、开关 TUN、开关代理）。
7. 不做可全屏的主窗口界面；设置与添加订阅都在面板内完成，只有日志这类另开窗口。
8. 不自绘仿制系统控件（`Toggle` / `Picker`），唯一例外是 §4.3 分段控件（需嵌磁贴尺寸）。
9. 不在 1Hz 数据上做布局动画或高频 VoiceOver 播报。
10. 不静默失败：任何失败必须有可见态（磁贴失败态 / banner / 底部行提示三者之一）。
11. 不引入第三方 UI 组件库（需先经用户确认）。

## 9. 验收标准

**结构**
