# 00 · 产品定义（Clash for macOS）

> 状态：v1 基线 · 最后更新 2026-11-13
> 本文只回答「做什么、给谁、不做什么」。技术细节见 `01-ARCHITECTURE.md`，界面见 `02-UI-SPEC.md`，节奏见 `03-ROADMAP.md`。

## 1. 一句话定位

一个住在 macOS 状态栏里的 Clash 客户端：像「控制中心」一样点开就能用，配置复杂度全部退到第二层。

## 2. 目标用户

| 用户 | 场景 | 在意什么 |
|---|---|---|
| 日常用户（主） | 一天开关代理十几次，偶尔切节点 | 一眼看懂现在通不通、快不快；不要弹网页面板 |
| 进阶用户 | 多订阅、多策略组、要 TUN | 能改端口 / 模式 / 规则，能看连接与日志 |
| 开发者（自己） | 内网 + 外网混合 | 内核可控、日志可查、配置不被自动改写 |

## 3. 与现有客户端的位置差异

| 产品 | 形态 | 我们的差别 |
|---|---|---|
| ClashX / ClashX Pro | 状态栏 + 弹出菜单（NSMenu 风格） | 我们做**浮层面板**（卡片、磁贴、曲线），不是长菜单 |
| Clash Verge Rev | 独立窗口 + 类 Web 仪表盘 | 我们不把流量图与配置摊在主界面；主界面只有 6 个动作 |
| Mihomo Party | 功能全，信息密度高 | 我们以「少即是快」为第一原则，进阶项进设置窗口 |

**设计立场**：状态栏面板 = 遥控器；设置窗口 = 控制台。两者不混。

## 4. v1 范围

### 做

1. 内核生命周期：启动 / 停止 / 崩溃自恢复；自带 mihomo 二进制
2. 系统代理：一键开关（含 HTTP/HTTPS/SOCKS），退出与崩溃后自动还原
3. 模式：规则 / 全局 / 直连
4. 节点与策略组：列表、选择、延迟测速、批量测速
5. 实时速率：上下行 + 迷你曲线
6. 订阅：URL 导入、更新、多配置切换、手动文件导入
7. TUN：开关 + 权限引导（privileged helper）
8. 连接列表：查看 / 关闭单条 / 全部关闭
9. 设置窗口：端口、开机自启、日志级别、外观（跟随系统）
10. 日志：文件 + 面板内最近 N 条

### 不做（v1 明确出界）

- 不内置、不推荐、不分发任何节点或订阅（合规底线）
- 不做 App Store 版本（helper + 内核无法通过审核）
- 不做规则编辑器（只读展示 + 打开文件）
- 不做多用户 / 团队配置同步
- 不做 iOS / iPad 版
- 不做主题市场、不做插件系统

## 5. 核心流程（首次启动）

```
启动 → 状态栏出现图标（灰=未运行）
  → 点开面板 → 空态「还没有配置」
  → 导入订阅 URL（或选择本地 YAML）
  → 生成运行配置 → 启动内核 → 图标变实心
  → 一键「系统代理」开 → 面板顶部显示速率
  → 需要更强接管时 → 开 TUN（弹管理员授权一次）
```

失败路径必须可解释：订阅拉取失败 / YAML 校验失败 / 端口占用 / helper 未安装，各给一句中文原因 + 一个动作按钮。

## 6. 术语（全项目统一，不要在代码与文案里混用）

| 术语 | 含义 |
|---|---|
| 内核 / core | mihomo 可执行进程 |
| 配置 / profile | 用户导入的 YAML（订阅产物），**原样保存，不覆写** |
| 运行配置 / runtime config | 由 profile + 应用设置生成的最终 YAML，交给内核 `-f` |
| 订阅 / subscription | 可定时更新的 profile 来源 URL |
| 策略组 / proxy group | 内核里的选择组（`select` / `url-test` / `fallback` 等） |
| 系统代理 / system proxy | 通过 `networksetup` 修改网络服务代理设置 |
| TUN | 内核接管网卡流量，需要 root |
| helper | 以 root 运行的特权辅助进程（LaunchDaemon） |

## 7. 非功能目标

- 冷启动到面板可交互 ≤ 1.5s（内核已在运行时 ≤ 300ms）
- 空闲内存 ≤ 120MB（不含内核）；面板展开动画不掉帧
- 面板常驻监听不可阻塞主线程：网络与内核通信全部 `async`，UI 状态 `@MainActor`
- 任何情况下都不得让用户机器「残留系统代理」——退出、崩溃、卸载三条路都要还原
- 全量界面支持深/浅色、VoiceOver、Reduce Motion、键盘可达

## 8. 合规与命名

- 只分发客户端与内核二进制，不附带任何节点信息
- 内核为 GPL-3.0：独立进程调用 + 随包提供 LICENSE 与源码获取地址（见 `adr/0001`）
- 「Clash」名称与上游商标关系在发布前再确认；代码与文档内部沿用 Clash 不影响
