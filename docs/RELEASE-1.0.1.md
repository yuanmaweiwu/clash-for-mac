# Clash 1.0.1

本次更新只有一个主题：**切换订阅不再重启内核**。

## 配置热重载

- 切订阅 / 更新订阅改为就地重载配置（`PUT /configs`），复用当前端口与 secret，不再 `stop → start`
- 本地内核：0.69s → **0.055s**
- TUN 模式：0.477s → **0.053s**，root 内核 pid 与 utun 接口保持不变，连接不断
- 连续切换 5 次：3.28s → **0.272s**
- 任何一步失败（API 报错 / 校验未通过）都会**自动回退**到原来的 stop→start，并记录原因

## 同时修正

- 热重载后会主动刷新 `/proxies`，策略组与节点列表立即显示新订阅内容

## 说明

- 两天的连续运行数据：47.7 小时无重启、无崩溃，平均 CPU 0.12%，footprint 稳定在 49MB
- 上一个版本（1.0.0）已包含：XPC 崩溃修复、单实例、清理可恢复、网络检测不再自动刷新、系统代理开关提速、TUN geodata 门禁
- 测速并发限制与隐藏降频两项实验因实测无收益已在代码中回退，不包含在本版
