# Clash 1.0.0

首个正式版本：一个住在 macOS 菜单栏里的 Clash 客户端。

## 亮点

- **菜单栏控制中心**：340pt 面板，系统代理 / TUN / 代理模式 / 订阅一屏完成，无 Dock 图标
- **两种接管方式**：系统代理（退出自动还原）与 TUN（一次管理员授权，接管全部流量），互斥并明确提示
- **内核按需下载**：首次使用按架构下载 mihomo，SHA256 校验，镜像自动回退；也可选装内置内核的包
- **订阅与策略组**：多订阅并存、单条激活、独立更新；策略组单选，未被规则引用的组标注「未生效」
- **规则 / 连接 / 日志**：规则逐条列出目标，连接 2 秒刷新，日志支持级别过滤与导出
- **轻量**：空闲 footprint 约 28–36MB；面板首次显示才创建 SwiftUI 树
- **可恢复**：单实例保护；退出前还原代理并停内核；崩溃后重启会清理孤儿内核

## 安装包

| 文件 | 架构 | 内置内核 |
|---|---|---|
| `Clash-1.0.0-arm64.dmg` / `.zip` | Apple Silicon | 否（首次使用下载，约 20MB） |
| `Clash-1.0.0-arm64-kernel.dmg` / `.zip` | Apple Silicon | 是（装完即用，体积 +56MB） |
| `Clash-1.0.0-x86_64.dmg` / `.zip` | Intel | 否 |
| `Clash-1.0.0-x86_64-kernel.dmg` / `.zip` | Intel | 是 |

每个产物附同名 `.sha256`。

## 系统要求

- macOS 15.0 Sequoia 及以上
- 仅 TUN 需要一次管理员授权；系统代理不需要密码

## 注意

- ad-hoc 签名、未公证：首次打开请右键 →「打开」
- 目前仅支持 mihomo 内核
