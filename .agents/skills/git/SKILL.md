# Git：自动本地提交与可回退

> 目的：AI 改文件时**自动**留下本地可回退点，用户不必再说「提交」。远程默认只读。
> 细则按需读 references；**禁止**一次读完。
> **覆盖**通用「未要求不提交」：在本仓库，满足下方时机即**授权本地 commit**；仍**不授权**远程写。

## 0. 硬闸（远程优先）

1. **自动本地 ≠ 自动远程**：完成一块工作 → 自动 `git commit`；**绝不**自动 `push` 或任何远程写。
2. **除非用户当轮明确要求，禁止一切远程写**（push / 删远程分支 / 删远程仓 / `gh repo delete` 等）。细则见 [references/safety.md](references/safety.md)。
3. **删除远程仓库**：默认拒绝；仅仓库全名 +「确认删除远程」+ 二次确认。
4. **禁止**改 `git config`；禁止未确认的 `reset --hard` / `clean -fd`。
5. **禁止**交互式命令：`rebase -i`、`add -i` 等。
6. **禁止**提交密钥：`.env`、含真实密码 / Token 的文件。
7. Hook 失败 → **新 commit 修复**，禁止擅自 `--no-verify`。
8. 不擅自 `commit --amend`（仅符合 amend 条件时）。

## 1. 何时自动本地提交（无需用户开口）

工作区有相关改动，且出现下列**任一**时机 → **立即**按 §2 本地 commit，**不要问**「要不要提交」：

| 时机 | 示例 |
|------|------|
| **小功能 / 一条需求落地** | 某功能可用、某脚本能跑通 |
| **bug 已修复** | 复现路径消失、对应测试或手工验证通过 |
| **新增能力收尾** | 新配置、新脚本、新技能、文档 / 约定同步完成 |
| **一块可验证改动结束** | 该跑的检查 / 测试已跑完，准备回报用户 |
| **大改 / 试错 / 换方案前** | 先 commit 当前可回退点再动手 |
| **用户明确说提交 / 检查点** | 立刻 commit（与自动规则相同流程） |

### 不要自动 commit

- 改到一半、语法 / 构建 / 校验失败、还在连改同一意图 → 等收尾再提交。
- 工作区只有无关噪音或密钥文件 → 不提交；有密钥则排除并警告。
- 用户当轮明确说「先别提交 / 不要 commit」→ 遵守，直到其取消。
- **纯讨论、未改文件** → 无 commit。

### 粒度

- **一个意图一条 commit**（修一个 bug、加一个小功能）；不要把无关改动捆一起。
- 同一轮对话连续完成多块独立意图 → **多条**本地 commit，不要攒成一个大球。

## 2. 提交流程（本地）

先并行收集，再分析后提交：

1. `git --no-optional-locks status`
2. `git --no-pager diff`（含已暂存）
3. `git --no-pager log -8 --oneline`（对齐语气）

然后：

1. 只 stage 相关文件；排除密钥与无关噪音。
2. 中文 message（见 [references/commit-message.md](references/commit-message.md)）。
3. `git commit`（HEREDOC）。
4. `git status` 确认。
5. **停止**——除非用户明确 push。
6. 向用户回报时可**一句**带过本地 commit（message 摘要）；**不要**邀功式长篇，更不要擅自 push。

检查点（大改前）message：`检查点：<当前可回退状态一句话>`（对象仍用反引号，见 commit-message）。

## 3. 回退（出问题后）

| 情况 | 优先 |
|------|------|
| 改坏但未 commit | 停手；diff 定位；必要时 `restore` 指定文件 |
| 已有自动 / 检查点 commit | `git log` 找好点 → 用户确认后 revert 或新提交修复 |
| 试错在分支上 | 切回主线 / 丢弃试错分支（须用户确认） |

**禁止**未确认就 `reset --hard` 清掉未提交工作。

## 4. 远程写（仅显式授权）

| 用户说法 | 远程写 |
|----------|--------|
| （无话 / 只说做功能） | 否；仅自动本地 commit |
| 「提交」「检查点」 | 否；只本地 |
| 「push」「推到远程」「推送到 origin」 | 是；仅 push 当前分支 |
| 模糊「同步 / 发布 / 顺便推」 | 否 |
| 删远程仓且无全名 + 确认 | 否 |

Push 时：再 `status` → `git push`（或首次 `-u`）→ **禁止**默认 force；`main` / `master` 禁止 force。
