# 中文 Commit Message

本仓库沿用：**中文、动词开头、短句**；对象用反引号标出。不要用英文 Conventional Commits（`feat:` / `fix:`）。

## 格式

单行优先：

```text
<动词> `<对象>`[补充说明]
```

需要补「为什么」时：

```text
<动词> `<对象>`：<原因或结果>
```

一般 ≤50 字；第二段（空行后）最多 1～2 句中文说明，禁止堆文件列表。

## 反引号：只包对象

**包「可检索的对象 / 标识」，不包动词，不包整句，不包冒号后原因。**

| 包 | 不包 |
|----|------|
| 技能名：`git` | 动词：新增 / 修复 / 更新 |
| 文件或路径：`AGENTS.md`、`.agents/skills/git` | 整句 message |
| 模块 / 配置名：`config.yaml` | 纯泛称且无具体名：「文档」「技能」单独出现时 |
| 命令 / 任务：`make test`、`rule-set` | 冒号后的原因白话 |
| 稳定专有名（可选）：`Clash`、`Gitea` | 密钥、密码 |

一句话：动词白话 + `` `改了谁` ``；原因不包。

## 动词

| 动词 | 何时 |
|------|------|
| 新增 | 全新能力、文件、技能 |
| 更新 | 已有能力增强、约定 / 文档同步 |
| 修复 | bug |
| 优化 | 结构 / 体验 / 性能，对外行为大体不变 |
| 重构 | 行为不变的结构调整（少用） |
| 回退 | 明确撤销 |
| 检查点 | 仅为可回退基线，尚未形成完整产品意图时用 |

## 范例

- 新增 `git` 自动本地提交技能
- 更新 `AGENTS.md` 补充技能入口与优先级
- 优化 `.agents/skills/git` 提交时机说明
- 修复 `README.md` 安装步骤缺少代理说明
- 检查点：调整配置前的可用状态
- 新增 `.agents/README.md` 技能目录说明

## 禁止

- 纯英文：`update stuff`、`fix bug`、`WIP`
- 只列文件：`改 a.go b.go`（应用动词 + `` `路径或模块` ``）
- 空洞：`更新`、`修改代码`
- 反引号包动词或整句：`` `新增` xxx ``、`` `整句...` ``
- 把密钥、密码写进 message
